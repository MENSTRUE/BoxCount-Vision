# Research reports — immutable evidence

`audit/`: dataset inventory, label validity, filename metadata, exact SHA and sampled near-duplicate checks. `evaluation/`: `final_heldout_detection_metrics.csv`, `heldout_count_metrics.csv`, `heldout_count_predictions.csv`. `experiments/`: train/validation selection CSVs, candidate model selection, `research_report.json`. `forecasts/` reserved in existing scaffold; this is object detection, not forecasting. Do not overwrite reports from a prior run without versioning. See [evaluation](../docs/en/evaluation.md).
